# FreeCAD_XYZ

FreeCAD 宏脚本：根据选中的几何元素设置参考点，并将模型平移到该点作为临时原点，再围绕该点按 X / Y / Z 轴旋转。

适用于 **FreeCAD 1.1**。

## 功能说明

运行宏后，会根据当前选择确定参考点，并完成以下操作：

1. 在控制台与面板中显示参考点坐标 `(X, Y, Z)`
2. 平移整个模型，使该参考点成为临时全局原点 `(0, 0, 0)`
3. 弹出任务面板，可输入绕 X / Y / Z 轴的旋转角度，并实时预览
4. 点击「确定」保留结果；点击「取消」撤销本次全部操作（平移 + 旋转）

### 支持的选择类型

| 选择对象 | 参考点位置 |
| --- | --- |
| 顶点（Vertex） | 该顶点 |
| 直线（Edge-Line） | 直线中点 |
| 圆 / 圆弧（Edge-Circle） | 圆心 |
| 其他曲线 | 曲线质心 |
| 面（Face） | 面的几何中心（质心） |

脚本会自动处理 Body / Part / Link 等容器内的全局坐标修正，避免参考点计算错误导致模型“飞走”。

## 安装说明

### 方法一：复制到宏目录（推荐）

1. 打开 FreeCAD
2. 菜单：**宏 → 宏…**，查看窗口中显示的「用户宏位置」路径  
   （Windows 下常见类似：`C:\Users\<用户名>\AppData\Roaming\FreeCAD\Macro`）
3. 将本仓库中的 `XYZ.FCMacro` 复制到该宏目录
4. 重启 FreeCAD（或刷新宏列表）
5. 再次打开 **宏 → 宏…**，在列表中选中 `XYZ.FCMacro`，即可执行

### 方法二：在 FreeCAD 中新建宏并粘贴

1. 打开 FreeCAD
2. 菜单：**宏 → 宏… → 创建**
3. 输入宏名称（例如 `XYZ`），确认后打开宏编辑器
4. 将 `XYZ.FCMacro` 的全部内容粘贴进去并保存
5. 在宏对话框中选中该宏并执行

### 环境要求

- FreeCAD 1.1（脚本基于该版本编写）
- 已启用图形界面（依赖 `FreeCADGui` 与 `PySide`）
- 当前有打开的文档，并在 3D 视图中完成选择后再运行

## 使用方法

1. 在 FreeCAD 中打开或创建文档，并确保模型已显示在 3D 视图中
2. 在 3D 视图中选中以下之一：
   - 一个顶点
   - 一条直线
   - 一段圆弧或一个圆
   - 一个面
3. 运行本宏：
   - **宏 → 宏…** → 选中 `XYZ.FCMacro` → **执行**
   - 也可将该宏加入工具栏 / 快捷键后一键运行
4. 查看弹出的「设置参考点并旋转」面板：
   - 上方显示选中类型与原始坐标
   - 下方可分别调整绕 X / Y / Z 轴的角度（单位：度，范围约 `-360°` ~ `360°`）
   - 调整角度时会实时预览模型朝向
5. 满意后点「确定」保留结果；不满意点「取消」恢复到运行宏之前的状态

### 操作提示

- 必须先选中几何元素再运行宏，否则会提示错误
- 旋转顺序为：**先绕 X，再绕 Y，最后绕 Z**
- 旋转轴始终通过选中的参考点（该点已被移到全局原点，旋转时该点本身不动）
- 仅对文档中的顶层对象做平移/旋转，避免容器内子对象被重复变换

## 常见问题

**Q：提示“请先在3D视图中选中……”怎么办？**  
A：先在 3D 视图点选顶点 / 边 / 面，再执行宏。

**Q：提示“未能识别选中的几何元素”？**  
A：请尽量选中明确的顶点、直线边、圆/圆弧边或面，不要只选中整个对象而不选子元素。

**Q：提示“当前没有打开的文档”？**  
A：先新建或打开一个 `.FCStd` 文档后再运行。

**Q：点了取消，模型会怎样？**  
A：会撤销本次宏的全部平移与旋转，恢复到运行前的状态。
